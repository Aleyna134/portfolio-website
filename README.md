# Futuristic Portfolio Website

Welcome to my personal portfolio website!

🌍 **Live Demo:** [https://aleyna134.github.io/portfolio-website/](https://aleyna134.github.io/portfolio-website/)

This is a modern, dark-themed, and fully responsive personal portfolio designed with a futuristic "glassmorphism" aesthetic. It features smooth scroll animations, a custom animated robot intro, and an interactive particle background.

## Features
- **Bilingual Support:** Instantly switch between Turkish (TR) and English (EN) without page reloads.
- **Interactive UI:** Canvas particle system that interacts with the mouse cursor.
- **Custom Animations:** A unique, CSS-driven walking robot intro sequence.
- **Responsive Design:** A fluid CSS Grid and Flexbox layout that looks great on mobile, tablet, and desktop.
- **No Heavy Frameworks:** Built entirely with Vanilla HTML5, CSS3, and JavaScript for maximum performance.
